IDENTITY

Developer with an obsession for taste, speed, and structural integrity.

Hi, I’m Sabith. I work at the intersection of creative design and engineering rigor. I believe the best digital products are born when a single builder understands both the subtle nuances of typography and interaction design, as well as the deeper complexities of socket event loops, concurrency, and embedded memory constraints.

Over the years, I’ve built cross-platform mobile apps using Flutter and Dart, scalable backend microservices with Node.js and FastAPI, local-first RAG pipelines utilizing Ollama LLMs, and physical computing nodes built on ESP8266 microcontrollers with real-time MQTT telemetry.

I take pride in writing clean, modular code that avoids bloated dependencies and delivers tactile, responsive experiences for real people.

PRINCIPLES

How I Build

01 / Performance First

Whether it’s a Flutter isolate rendering at 120 FPS or a backend query returning in under 20ms, speed and responsiveness are treated as fundamental user rights, not afterthoughts.

02 / Local-First & Privacy

Prioritizing offline SQLite caches, zero unnecessary analytics tracking, and on-device AI inference so that user data remains in user control.

03 / Cross-Disciplinary Craft

Connecting the dots between firmware flashing on microcontrollers, web animation kinetics, and defensive cybersecurity hygiene.
